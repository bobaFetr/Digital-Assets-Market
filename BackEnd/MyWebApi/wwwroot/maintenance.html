Maintenance Window
CI
Scheduled platform update

CryptoMatrix is temporarily offline for maintenance.

We are applying updates to improve platform stability, security, and account experience. The dashboard and API are paused for a short time, and service will return as soon as the work is complete.

System status: planned maintenance
Availability Public pages and authenticated tools are temporarily unavailable.
API state Requests return a temporary unavailable response while maintenance mode is enabled.
Restore Turn off the Render maintenance environment variable to bring the platform back online.

Platform status

Paused
maintenance mode active

The site shell is live, but account actions, trading flows, and API operations are intentionally blocked.

User impact

Read-only break

Sign in, wallet actions, trading, and dashboard navigation should wait until maintenance mode is disabled.

Deployment switch

Render env var

This page is controlled from the backend, so Render can switch it on or off without changing frontend routes.

Maintenance details
Recommended env var
MAINTENANCE_MODE=true

Set this in Render to show the maintenance page for all normal site routes.

Disable maintenance
MAINTENANCE_MODE=false

Or remove the variable entirely, then let Render restart the service.

Alternate supported names
MAINTENANCE_ENABLED

The backend also accepts `ENABLE_MAINTENANCE_PAGE` and `Maintenance__Enabled`.

What is happening right now
Step 1
Render starts the API with maintenance mode enabled.
Step 2
Requests for normal web routes are redirected to this maintenance screen instead of the React app.
Step 3
API routes return a temporary unavailable response until the environment variable is turned off.
